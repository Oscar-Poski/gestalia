# gestalia.mx

Landing page de Gestalia — adopción de IA para PyMEs en México. Plan completo en [`docs/plan-landing.md`](docs/plan-landing.md).

Stack: Astro 5 + Tailwind CSS 4.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # genera dist/
```

- Datos de contacto (WhatsApp, agenda, correo): `src/config.ts`
- Tokens de marca (colores, fuentes): `src/styles/global.css`
- Secciones: `src/components/`
